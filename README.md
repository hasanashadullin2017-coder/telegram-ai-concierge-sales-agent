# ИИ-консьерж и ИИ-продажник для Telegram

Система автоматической обработки входящих обращений в Telegram с разделением на два этапа: консьерж-агент и менеджер-продажник.

## Что делает система

Бот автоматически:

- принимает сообщения из Telegram
- обрабатывает текстовые и голосовые сообщения
- распознаёт голос через OpenAI
- ведёт первичный диалог через ИИ-консьержа
- собирает данные клиента
- сохраняет состояние диалога и память в Redis
- передаёт клиента ИИ-менеджеру
- продолжает диалог на этапе продажи

## Логика работы

### 1. ИИ-консьерж
Консьерж — это первая точка контакта с пользователем.

Он поэтапно собирает:
- имя
- телефон
- адрес
- причину обращения

После этого данные сохраняются, и клиент автоматически передаётся следующему агенту.

### 2. ИИ-менеджер / продажник
После квалификации клиента подключается второй агент.

Он:
- продолжает общение как живой менеджер
- учитывает уже собранные данные
- отвечает по сути запроса
- мягко ведёт клиента к следующему шагу: консультации, заказу или созвону

## Технологии

- n8n
- Telegram Bot API
- OpenAI
- Redis
- Redis Chat Memory

## Особенности

- поддержка голосовых сообщений
- автоматическая транскрибация аудио
- хранение состояния диалога в Redis
- Redis-память для многошагового общения
- передача клиента между агентами
- автоматизация первичной квалификации лида

## Архитектура

Telegram → n8n → ИИ-консьерж → Redis → ИИ-менеджер → ответ клиенту

## Для чего подходит

Система может использоваться для:
- обработки входящих заявок
- первичной квалификации лидов
- автоматизации Telegram-продаж
- онлайн-консультаций
- замены первого менеджера в воронке
